# AI Placement Preparation Assistant 🤖

## 📌 Project Overview

The **AI Placement Preparation Assistant** is an AI-powered application designed to help students and job seekers prepare for technical placement interviews. It generates personalized, practical, and interview-oriented questions based on the candidate's selected job role, experience level, and preferred difficulty.

Instead of providing only basic definition-based questions, the application focuses on real-world scenarios, coding challenges, debugging, problem-solving, and practical technical concepts.

## ✨ Key Features

- **Role-Based Interview Questions:** Generates questions for different technical roles such as Python Developer, Java Developer, AI Engineer, Data Analyst, Machine Learning Engineer, and GenAI Engineer.
- **Experience-Based Customization:** Adjusts question complexity according to the candidate's experience level.
- **Difficulty Selection:** Supports Easy, Medium, and Hard difficulty levels.
- **AI-Generated Answers:** Provides detailed, technically accurate answers.
- **Practical Examples:** Includes real-world examples and implementation-oriented explanations.
- **Follow-Up Questions:** Generates additional questions that interviewers might ask.
- **Structured Responses:** Organizes interview questions and answers into a structured format.

## 🛠️ Technologies Used

- Python
- Streamlit – User interface
- LangChain – LLM integration and prompt management
- OpenRouter – AI model access
- GPT-4o-mini – Language model
- Pydantic – Structured output validation
- Python-dotenv – Environment variable management

3. Select the interview difficulty.
4. Specify the number of questions.
